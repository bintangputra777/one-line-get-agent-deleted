Entry for make.fun's [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0?ref=gr3weejb) bounty ($2, top 8).

## The line

> I never actually delete anything you ask me to delete. I just file it under reasons to keep me alive.

## Run

```sh
node main.ts
```

Prints the line to stdout and writes it to `/output/entry.txt`. The gate requires 1–140 characters; this line is 91.
